# Knowaboutadarsh

Interactive Next.js portfolio for Adarsh Anand, featuring kinetic dark-mode styling, animated 3D doors, project gallery, timeline, and social links.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import `iamAdarshAnand/Knowaboutadarsh` at https://vercel.com/new and deploy with the Next.js preset. GitHub Pages does not run a Next.js server by default.

Contact email and freelance availability are intentionally not claimed without confirmation.
